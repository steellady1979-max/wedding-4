# wedding 4

შექმენი ახალი, ულტრა-მინიმალისტური და ელეგანტური ქორწილის სადესანტო გვერდი (Landing Page) ქართულ ენაზე შემდეგი დეტალებით: აუცილებლად დაიწყე მიმაგრეებული ვიდეოთი სანამ უშუალოდ ლენდინგზე გადავა ადამიანი. დაეწეროს ნინი & ტატო

1. დიზაინი და ფერთა პალიტრა:

ძირითადი ფონი უნდა იყოს რბილი, თბილი კრემისფერი (Warm Cream / Soft Beige #FBF9F5 ან მსგავსი ტონალობა).

შრიფტები: დახვეწილი, თხელი სერიული შრიფტი სათაურებისთვის და სუფთა სან-სერიფი ძირითადი ტექსტისთვის.

ატმოსფერო: არისტოკრატული, ჰაეროვანი და მინიმალისტური.

2. ვიზუალური ნაწილი:

მთავარ ეკრანზე (Hero Section) ჩასვი მოწოდებული ანიმაციური ვიდეო (შატო მუხრანის ფონზე წყვილი).

3. სექციები და სტრუქტურა (მხოლოდ საჭირო ინფორმაცია):

სათაური: ნინი & ტატო

თარიღი: 17 სექტემბერი

ლოკაცია: შატო მუხრანი (დაამატე ღილაკი 'რუკაზე ნახვა').

დღის განრიგი (Timeline): მარტივი და სუფთა სიით (მაგ: სტუმრების მიღება, ცერემონია, სადილი).

დრესკოდი (Dress Code): მინიმალისტური მითითება ფერებსა და სტილზე კრემისფერ და პასტელურ ტონებში.
